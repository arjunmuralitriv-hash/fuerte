# مسرد المصطلحات

تعريفات مبسطة للمصطلحات التقنية المستخدمة في هذا الموقع.

## المصطلحات التقنية (40)

| # | المصطلح المعتمد بالعربية | التعريف | ملاحظات الاستخدام | English |
|---|---|---|---|---|
| 1 | أنظمة التيار الخفيف (ELV) | أنظمة المباني التي تعمل بجهد كهربائي منخفض جدًا، مثل كاميرات المراقبة والتحكم في الدخول وإنذار الحريق والنداء العام وشبكات البيانات. | يُكتب «التيار الخفيف» أو ELV بعد أول ذكر. | ELV systems |
| 2 | الكابلات الهيكلية | نظام موثق وفق المعايير من الكابلات النحاسية والألياف الضوئية ولوحات التوصيل والخزائن، ينقل بيانات المبنى واتصالاته الصوتية. | لا يُستخدم «تمديد الشبكات» في العناوين. | Structured cabling |
| 3 | Cat6 | كابل نحاسي من الفئة 6: تردد 250 MHz، وسرعة 1 Gbps حتى 100 m، و10 Gbps حتى نحو 55 m. | يُكتب «Cat6» بالحروف اللاتينية. | Cat6 |
| 4 | Cat6A | كابل نحاسي من الفئة 6 المعززة: تردد 500 MHz، وسرعة 10 Gbps حتى 100 m، وهو الأنسب لتغذية PoE عالية القدرة. | يُكتب «Cat6A». | Cat6A |
| 5 | الألياف الضوئية (أحادية النمط ومتعددة الأنماط) | كابل زجاجي ينقل البيانات على هيئة ضوء لمسافات طويلة وبسرعات عالية جدًا. الأحادية النمط (OS2) للمسافات الطويلة، والمتعددة الأنماط (OM3 وOM4 وOM5) داخل المباني. | تُكتب رموز الفئات بالحروف اللاتينية. | Fibre (single-mode, multi-mode) |
| 6 | اختبار OTDR | اختبار بجهاز قياس الانعكاس الضوئي في المجال الزمني، يقيس طول الليف الضوئي وفقده ويحدد مواقع الأعطال. | | OTDR testing |
| 7 | اللحام الانصهاري للألياف الضوئية | وصل ليفين ضوئيين وصلًا دائمًا بصهرهما معًا بقوس كهربائي. | | Fusion splicing |
| 8 | تغذية الطاقة عبر الإيثرنت (PoE) | نقل الطاقة الكهربائية والبيانات عبر كابل الشبكة النحاسي نفسه إلى الكاميرات والهواتف ونقاط الوصول. | | Power over Ethernet (PoE) |
| 9 | جدار الحماية من الجيل التالي (NGFW) | جدار حماية يفحص التطبيقات والمستخدمين والتهديدات، لا المنافذ والعناوين فقط. | | Next-generation firewall (NGFW) |
| 10 | نظام مراقبة الشبكة (NMS) | برنامج يراقب أجهزة الشبكة ووصلاتها وينبّه المهندسين إلى الأعطال أو البطء. | | Network monitoring system (NMS) |
| 11 | خريطة حرارية لتغطية Wi-Fi | خريطة ملونة لقوة الإشارة اللاسلكية على مخطط الطابق، مستخلصة من مسح تنبؤي أو ميداني. | | Wi-Fi heat-map |
| 12 | تقسيم الشبكة إلى مناطق معزولة | تقسيم الشبكة إلى مناطق منفصلة (غالبًا عبر VLAN) بحيث لا تنتقل مشكلة أو مهاجم من منطقة إلى أخرى بحرية. | | Network segmentation |
| 13 | الاتصال الصوتي عبر بروتوكول الإنترنت (VoIP) | مكالمات هاتفية تُنقل عبر شبكة البيانات بدلًا من خطوط الهاتف التقليدية. | | VoIP |
| 14 | مقسم هاتفي IP-PBX | نظام هاتفي للشركات يوجّه المكالمات عبر شبكة تعمل ببروتوكول الإنترنت. | يُعرف محليًا أيضًا باسم «سنترال IP». | IP-PBX |
| 15 | نظام تخطيط موارد المؤسسات (ERP) | برمجيات أعمال تربط المالية والمشتريات والمخزون والموارد البشرية وغيرها في نظام واحد. | | Enterprise resource planning (ERP) |
| 16 | مركز البيانات | غرفة أو مبنى يضم الخوادم وأجهزة التخزين والشبكات، مع تحكم في الطاقة والتبريد والأمن. | الجمع «مراكز البيانات». | Data center |
| 17 | مركز بيانات معياري | خزانة أو صف أو حاوية مصممة مسبقًا تضم أنظمة الطاقة والتبريد والمراقبة الخاصة بها. | | Modular data center |
| 18 | الأرضية المرتفعة | أرضية مرفوعة من بلاطات قابلة للفك، توفر مساحة أسفلها للكابلات وهواء التبريد. | | Raised floor |
| 19 | عزل الممرات الساخنة والباردة | حواجز مادية تفصل الهواء البارد الداخل إلى الخزائن عن الهواء الساخن الخارج منها، لرفع كفاءة التبريد. | | Hot and cold aisle containment |
| 20 | نظام الطاقة غير المنقطعة (UPS) | بطاريات تُبقي الأجهزة عاملة أثناء انقطاع الكهرباء وحتى يبدأ المولد بالعمل. | | UPS |
| 21 | التبريد الدقيق | تكييف مصمم لأجهزة تقنية المعلومات، يتحكم بدقة في درجة الحرارة والرطوبة، ويشمل التبريد بين الخزائن (In-row). | | Precision cooling |
| 22 | نظام الإطفاء بغاز FM-200 | نظام إطفاء بغاز نظيف يُخمد الحرائق دون ماء أو مخلفات. | اسم تجاري يُكتب بالحروف اللاتينية. | FM-200 |
| 23 | التعافي من الكوارث (DR) | الخطة والتقنية اللازمتان لاستعادة أنظمة تقنية المعلومات بعد عطل كبير، ويقاس بنقطة الاستعادة المستهدفة (RPO، أي حجم البيانات المسموح بفقده) وزمن الاستعادة المستهدف (RTO، أي مدة التوقف المسموح بها). | | Disaster recovery (DR) |
| 24 | شبكة Spine-Leaf | شبكة مركز بيانات بطبقتين يتصل فيها كل مبدّل طرفي بكل مبدّل في العمود الفقري، ما يوفر زمن تأخير منخفضًا يمكن التنبؤ به. | | Spine-leaf network |
| 25 | كاميرات المراقبة (CCTV) | كاميرات ومسجلات تُستخدم للمراقبة بالفيديو. | تُستخدم «CCTV» في العناوين عند الحاجة، و«المراقبة بالفيديو» صيغةً بديلة. | CCTV |
| 26 | نظام إدارة الفيديو (VMS) | برنامج يسجل الفيديو من كاميرات متعددة ويديره ويعرضه. | | Video management system (VMS) |
| 27 | التعرف الآلي على لوحات المركبات (ANPR) | كاميرات وبرمجيات تقرأ لوحات أرقام المركبات. | لا تُستخدم LPR أو ALPR. | ANPR |
| 28 | تحليلات الفيديو الذكية | برمجيات تحلل الفيديو تلقائيًا، مثل عدّ الأشخاص أو كشف التسلل. | | Video analytics |
| 29 | مركز القيادة والتحكم | غرفة أو منصة يراقب فيها المشغلون الأحداث الأمنية في مواقع متعددة ويستجيبون لها من واجهة واحدة. | | Command and control center |
| 30 | أنظمة التحكم في الدخول | نظام يحدد من يدخل من أي باب أو بوابة أو منطقة ومتى، باستخدام البطاقات أو بيانات الاعتماد على الجوال أو القياسات الحيوية. | | Access control |
| 31 | أنظمة كشف التسلل | حساسات إنذار تكشف الدخول غير المصرح به، مثل حساسات الحركة والأبواب وكسر الزجاج. | في سياق الأمن السيبراني يُكتب «كشف التسلل إلى الشبكة». | Intrusion detection |
| 32 | نظام إنذار الحريق المعنوَن | نظام إنذار حريق يحدد الجهاز الذي أطلق الإنذار بعينه، لا المنطقة فقط. | | Addressable fire alarm |
| 33 | نظام النداء العام (PA) والإخلاء الصوتي | نظام للإعلانات والموسيقى؛ ويبث الإخلاء الصوتي تعليمات طوارئ مسجلة عند تفعيل إنذار الحريق. | | Public address (PA) and voice evacuation |
| 34 | نظام إدارة المباني (BMS) | نظام يراقب أنظمة التكييف والإضاءة والطاقة والمعدات في المبنى ويتحكم فيها من مكان واحد. | | Building management system (BMS) |
| 35 | تقييم الثغرات واختبار الاختراق (VAPT) | فحص الأنظمة بحثًا عن نقاط الضعف، ثم محاولة استغلالها كما يفعل المهاجم. | | VAPT |
| 36 | مركز العمليات الأمنية (SOC) | فريق ومجموعة أدوات تراقب التهديدات السيبرانية وتكشفها وتستجيب لها على مدار الساعة. | | Security operations center (SOC) |
| 37 | نظام إدارة المعلومات والأحداث الأمنية (SIEM) | برنامج يجمع سجلات الأحداث الأمنية ويربط بينها. | | SIEM |
| 38 | الحوكمة وإدارة المخاطر والامتثال (GRC) | السياسات وإدارة المخاطر والضوابط التي تثبت أن المؤسسة تفي بالتزاماتها القانونية والتنظيمية. | | Governance, risk and compliance (GRC) |
| 39 | عقد الصيانة السنوية (AMC) | عقد خدمة سنوي يشمل الصيانة الوقائية والاستجابة للأعطال وفق أزمنة متفق عليها. | يُكتب «AMC» أو «عقد الصيانة» بعد أول ذكر. | Annual maintenance contract (AMC) |
| 40 | اتفاقية مستوى الخدمة (SLA) | الجزء من العقد الذي يحدد أهداف خدمة قابلة للقياس، مثل أزمنة الاستجابة والاستعادة. | | Service level agreement (SLA) |
