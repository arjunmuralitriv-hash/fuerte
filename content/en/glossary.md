# Glossary

Plain-English definitions of the technical terms used on this website.

## Technical terms (40)

| # | Preferred EN form | Definition | Usage notes | Arabic |
|---|---|---|---|---|
| 1 | ELV systems | Extra-low voltage building systems, such as CCTV, access control, fire alarm, PA and data networks, that run at low voltage. | Write "ELV" after first use. Avoid "low current" except as an SEO variant. | |
| 2 | Structured cabling | A standards-based, documented system of copper and fibre cables, patch panels and racks that carries a building's data and voice. | Not "network cabling" in headings. | |
| 3 | Cat6 | Category 6 copper cable: 250 MHz, 1 Gbps to 100 m, 10 Gbps up to about 55 m. | Write "Cat6", not "CAT-6" or "Category 6". | |
| 4 | Cat6A | Augmented Category 6 copper cable: 500 MHz, 10 Gbps to 100 m, better for high-power PoE. | Write "Cat6A". | |
| 5 | Fibre (single-mode, multi-mode) | Glass cable that carries data as light over long distances at very high speed. Single-mode (OS2) for long runs; multi-mode (OM3, OM4, OM5) inside buildings. | British spelling "fibre". | |
| 6 | OTDR testing | Optical time-domain reflectometer testing: measures a fibre's length and losses and locates faults. | | |
| 7 | Fusion splicing | Joining two optical fibres permanently by melting them together with an electric arc. | | |
| 8 | Power over Ethernet (PoE) | Delivering electrical power and data over the same copper network cable to cameras, phones and access points. | | |
| 9 | Next-generation firewall (NGFW) | A firewall that inspects applications, users and threats, not just ports and addresses. | | |
| 10 | Network monitoring system (NMS) | Software that watches network devices and links and alerts engineers to failures or slowdowns. | | |
| 11 | Wi-Fi heat-map | A colour map of wireless signal strength across a floor plan, from a predictive or on-site survey. | Hyphenate "heat-map". | |
| 12 | Network segmentation | Dividing a network into separate zones (often VLANs) so a problem or attacker in one zone cannot freely reach others. | | |
| 13 | VoIP | Voice over IP: phone calls carried over a data network instead of traditional phone lines. | | |
| 14 | IP-PBX | A business phone system that routes calls over an IP network. | Hyphenated. | |
| 15 | Enterprise resource planning (ERP) | Business software that connects finance, procurement, inventory, HR and other processes in one system. | | |
| 16 | Data center | A room or building that houses servers, storage and network equipment with controlled power, cooling and security. | Fixed term: US spelling "center" (industry and search usage). | |
| 17 | Modular data center | A pre-engineered rack, row or container that includes its own power, cooling and monitoring. | | |
| 18 | Raised floor | An elevated floor of removable tiles that creates space underneath for cables and cooling air. | | |
| 19 | Hot and cold aisle containment | Physical barriers that separate the cold air entering racks from the hot air leaving them, improving cooling efficiency. | | |
| 20 | UPS | Uninterruptible power supply: batteries that keep equipment running through power cuts and until a generator starts. | | |
| 21 | Precision cooling | Air conditioning designed for IT equipment, with close control of temperature and humidity; includes in-row cooling. | | |
| 22 | FM-200 | A clean-agent gas fire suppression system that puts out fires without water or residue. | Trade name; keep in Latin script. | |
| 23 | Disaster recovery (DR) | The plan and technology to restore IT systems after a major failure, measured by RPO (data loss allowed) and RTO (downtime allowed). | | |
| 24 | Spine-leaf network | A two-layer data center network where every leaf switch connects to every spine switch, giving predictable low latency. | | |
| 25 | CCTV | Closed-circuit television: cameras and recorders used for video surveillance. | Use "CCTV" in headings; "video surveillance" as a variant. | |
| 26 | Video management system (VMS) | Software that records, manages and displays video from many cameras. | | |
| 27 | ANPR | Automatic number plate recognition: cameras and software that read vehicle number plates. | Not "LPR" or "ALPR". | |
| 28 | Video analytics | Software that analyses video automatically, for example to count people or detect intrusion. | | |
| 29 | Command and control center | A room or desk where operators monitor and respond to security events across sites from one interface. | Fixed term: US spelling "center", lower case in running text. | |
| 30 | Access control | A system that controls who can enter which door, gate or area, and when, using cards, mobile credentials or biometrics. | | |
| 31 | Intrusion detection | Alarm sensors that detect unauthorised entry, such as motion, door and glass-break sensors. In cyber security contexts write "network intrusion detection". | | |
| 32 | Addressable fire alarm | A fire alarm system that identifies the exact device in alarm, not just the zone. | | |
| 33 | Public address (PA) and voice evacuation | A system for announcements and music; voice evacuation plays recorded emergency instructions when the fire alarm activates. | | |
| 34 | Building management system (BMS) | A system that monitors and controls a building's HVAC, lighting, energy and plant from one place. | | |
| 35 | VAPT | Vulnerability assessment and penetration testing: scanning for weaknesses, then trying to exploit them as an attacker would. | | |
| 36 | Security operations center (SOC) | A team and set of tools that monitor, detect and respond to cyber threats around the clock. | Fixed term: US spelling "center". | |
| 37 | SIEM | Security information and event management: software that collects and correlates security logs. | | |
| 38 | Governance, risk and compliance (GRC) | Policies, risk management and controls that show an organisation meets its legal and regulatory obligations. | | |
| 39 | Annual maintenance contract (AMC) | A yearly service contract with preventive maintenance and agreed fault response. | Write "AMC" after first use. | |
| 40 | Service level agreement (SLA) | The part of a contract that sets measurable service targets, such as response and restoration times. | | |
